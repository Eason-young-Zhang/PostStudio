# 下一步行动方案：交互性能与配色提取

日期：2026-09-17。基线：本地测试版 0.2。

状态：P0～P3 已实现并完成本地验证；P4 自动测试、公开照片原生性能验证及安装包核心流程已完成，0.3.1 安装包签名及实际打开/提色流程校验通过。当前 32 项测试通过。旧的“限额前接续点”是历史记录，不代表目前仍未接入配色工具。README 是入口，最新完成状态见 IMPLEMENTATION.md。

实测：45.9MP 公开风景照片连续输入 10 秒，399 次图像绘制（约 40 fps），几何 P95 16.34 ms、图像绘制 P95 55.30 ms。42 张重复公开照片的压力场景峰值 RSS 3471.7 MiB。不是显示器物理延迟，也不是所有摄影素材的性能保证。

未覆盖的后续试用：作者真实胶片扫描、多种外部绘画软件往返、任意大规模单块移动的性能边界。新工具和交互已可使用，这些保持为明确的扩展验证事项。

## 目标与不可回退的约定

1. 画布拖动、整组网格和单块窗口拖动、滑块与键盘调参连续反馈，不需要停手才看到变化。
2. 新增与分块取样平行的“配色提取”二级工具，使用 Oklab 进行颜色归并，产出可编辑色卡与照片组合。
3. 固定工具输入；默认重新编辑原步骤，只有显式追加才处理当前结果。已有产物与下游步骤不自动更新。
4. 处理与素材始终在本机；不依赖在线服务。内部图像维持 16 位 TIFF 无损存储，界面颜色值不降低内部精度。
5. 保留单文件项目、自包含分享、导入降采样及原文件保留规则。50 MP 仅是单图开销上限场景；典型 42 张输入、单批最多 10 张。
6. 二级工具页面、滑块＋精确输入＋方向键、整组与单块窗口移动已经存在，本轮优化其体验，不重新定义单块为像素拼贴。

## P0：建立可比较的交互基线

- [x] 记录现版本在画布移动/缩放、滑块持续拖动、网格拖动和单块拖动中的耗时。
- [x] 分开测量事件到几何反馈、事件到图像呈现、输入解码、处理、缩放、界面绘制、停止操作到最终预览的时间，以及峰值内存。
- [x] 使用小图、约 24 MP 和接近 50 MP 的确定性测试素材；包含密集网格、透明边缘、细线与高频图案。真实照片仅本地使用，合成结果与真实素材结果分别标注。
- [x] 保留 64 → 80 像素重新编辑、输入不变、旧结果不变、单块窗口并集等回归验证。

代码核对发现：`app.py` 的预览计时器为 130 ms 单次防抖；`editor.py` 每次完整分辨率执行，再缩小到 1600；存在新请求时丢弃完成结果，主线程也要求 generation 严格相等。持续输入可能不断推迟启动或使完成结果无法显示。画布绘制的实际瓶颈仍需测量，不能把推测当作已定位问题。

交付：可重复执行的基准场景与基线报告。先测量再优化，不以硬件升级作为方案。

## P1：交互预览与正式计算分离

### 调度与反馈

- [x] 鼠标/键盘事件立即更新参数、选择框和网格几何；不得等后台全图处理。
- [x] 连续交互改为约 16～33 ms 节流，合并为一个最新待处理请求，不排长队，也不反复推迟首次反馈。
- [x] 为每次工具会话、输入、请求序号及预览质量分级。会话或输入不符的结果必须丢弃；同会话可呈现比当前显示更新的完成帧，避免持续拖动时长期无图像更新。
- [x] 画面标明正在更新；参数与几何保持最新，过渡帧不冒充最终结果。旧序号不得覆盖更新帧，同序号低质量不得覆盖高质量。
- [x] 停手约 150～250 ms 后请求精细预览；提交时读取最新参数快照，以完整工作分辨率执行。预览未完成不影响提交正确性。
- [x] 退出工具、切换输入、取消时失效旧任务；避免在主线程等待长任务而卡住界面。

### 图像与画布

- [x] 缓存源图显示层级、透明棋盘格及可复用信息；拖动画布图像只改变显示变换，不重新执行工具或解码。
- [x] 取样几何始终使用工作图像像素坐标。交互预览采用覆盖率/抗混叠处理，不能直接对缩略图按缩小后整数参数重新生成网格。
- [x] 小于屏幕像素的网格正确表达面积覆盖，避免重新引入伪摩尔纹；静止精细预览对照完整计算后缩小的参考图。
- [x] 单块移动优先更新受影响区域，并正确处理与其他窗口重叠的并集；全局参数变化重建所需掩膜。
- [x] 缓存有容量边界与淘汰策略；不能把 42 张图的完整 RGBA16 常驻内存。后台批处理串行或限制并发，优先保证前台操作。

验收目标（工程目标，非现有性能承诺）：缓存就绪后交互画面争取 30～60 fps，事件到几何反馈 P95 ≤ 50 ms、到交互图像反馈 P95 ≤ 100 ms；连续拖动 10 秒不出现持续停更、倒退或松手后长队回放。首次解码与精细预览时间单独报告。若不达标，根据测量调整缓存/绘制/计算实现，不以增加防抖等待掩盖卡顿。暂不预先承诺 GPU 重写。

交付：先提供可单独验证的性能改进构建与前后对比，再接入新工具。

## P2：Oklab 配色提取核心

### 确定的首版行为

- [x] 颜色数量 2～12，默认 5；滑块、精确值与方向键同步。
- [x] “面积主色”默认：优先覆盖主要颜色；“特色配色”：兼顾面积与颜色差异，保留部分小面积点睛色。后者不是语义识别，不声称理解主体。
- [x] 从固定输入建立确定性的分层像素样本，保留面积权重；不只把照片强烈缩小后聚类，防止细小点睛色被平均掉。
- [x] 正确执行 sRGB 解码到线性 RGB，再转换 Oklab；以感知差异归并。内部计算可用浮点，持久化遵守既定规格。
- [x] 完全透明像素不参与，半透明像素按 alpha 加权；黑白灰默认参与，透明棋盘格与排版背景不进入提取。
- [x] 每组代表色优先取靠近中心的实际输入样本颜色。纯色图或有效颜色不足时返回实际数量并提示；全透明图显示无可提取颜色，不虚构颜色。
- [x] 固定算法版本、种子与排序规则，保证同一输入和参数可复现。锁定/自定义颜色是明确的人工作品参数。
- [x] 支持锁色、图内取色替换、拖动排序。要求数量少于锁色数量时解释冲突并阻止该调整，不静默丢锁。
- [x] 手动替换后，按最终色卡重新估算归属比例；标注为估算占比，不等同于视觉重要性。排序不触发重新提取。

### 缓存与接口

- [x] 提取返回结构化数据：来源资产与步骤、算法版本、参数、颜色、估算权重、锁定状态与排序。分析、排版和正式图像生成分离。
- [x] 缓存按来源版本和分析设置区分；数量变化复用采样数据，位置/间距/顺序变化不重新分析像素。
- [x] 新工具稳定 ID 与参数版本接入注册接口；现有只返回图像的工具继续兼容，避免要求取样/反转色携带无关配色信息。

验收：已知面积的色块图占比在采样误差范围内；灰阶保持明度差异；雪地＋小红块对照两种模式；验证透明像素、单色、近似色、16 位输入、锁色冲突和可复现性。数值转换使用参考值/往返误差验证，艺术偏好另行由照片试用判断。

## P3：色卡编辑、组合与项目集成

- [x] 在画布选择图片后进入“配色提取”二级页面，中间实时展示照片＋色卡；源图和提取状态明确。
- [x] 支持等宽色条、按估算占比分段的色条，以及等分/比例色卡环。色卡环是作品排版，不伪称矢量示波器或精确色相位置分析。
- [x] 支持上/下/左/右、色条厚度或环大小、间距、留边、透明/自选/图内取色背景；颜色值与比例文字可选，默认不印在作品上。
- [x] 默认向照片外侧扩展作品尺寸，照片自身像素尺寸与比例不变；预览标明最终输出尺寸。
- [x] 支持仅生成色卡，或生成可拆分的“照片＋色卡”组合。组合引用原照片和配色资产，保存布局，不复制多份相同源图；正式合成图按需生成，导出时扁平化。
- [x] 需要后续像素工具处理组合时，从固定组合版本生成标准 RGBA16 输入；保留组合与旧版本，不隐式修改原图。
- [x] 配色快照可用于分块取样的背景候选色；修改原色卡不自动改变已有取样产物。
- [x] 项目清单保存配色、组合、布局及兼容版本；旧项目可打开，新字段不能被静默忽略后覆盖丢失。缓存删除或项目复制到另一位置后仍能完整恢复。
- [x] 接入预设、有序工作流和最多 10 张批处理：每张图片分别提色，版式复用；批量预览标明当前示例输入，显示逐项进度与失败信息。
- [x] 预设中的锁定颜色按显式颜色值复用；图内取色结果保存颜色快照，不把上一张图的取色坐标误用到下一张。
- [x] JPEG 导出明确合成透明背景；PNG/16 位 TIFF 遵循既有精度与透明规则。

验收：完整走通选图 → 调色数/模式 → 锁色与取色 → 排版 → 生成 → 继续取样/导出 → 保存关闭重开；重编辑生成新产物，旧资产不变。组合拆分、工作流中作为前后步骤、批量异形尺寸、离线打开与复制分享均有验证。

## 暂不纳入本轮

真实色相/彩度分布图（明度与中性色另行表达）、局部选区提色、跨多图共同配色、RAW、专业负片还原、节点工作流、GPU 全面重写、ASE 等专用色板交换格式。装饰色卡环已在本轮，不与分析分布图混淆。

## 四象限与执行中的判断

| 象限 | 内容 | 行动 |
| --- | --- | --- |
| 助手知、用户可能不知 | 防抖与节流差别；过期任务饥饿；Oklab 需正确线性化；面积主色和特色色的差别 | 用操作效果、对照素材和实测结果解释 |
| 用户知、助手不知 | 各张照片值得保留的点睛色、真实素材特性、创作上可接受的预览误差 | 自动结果允许手动修正，真实素材试用时记录偏好 |
| 双方已知 | 二级工具、两种拖动、独立产物、Oklab、两种提色倾向、色条/色卡环、离线与单文件项目 | 按基线执行，不重复要求确认 |
| 双方未知 | 特色配色权重、最佳样本量、实际性能、不同作品的色卡审美效果 | 小型对照实验与基准确定；记录参数依据，不能写成已测事实 |
