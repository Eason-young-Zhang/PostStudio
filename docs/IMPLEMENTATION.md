## 界面方向

- 视觉主张：深灰、安静的摄影工作台，图像是视觉中心，工具只在需要时占据注意力。
- 内容布局：顶部项目动作；左侧画布与素材总览；中央自由画布；工具在独立二级页面展示大幅预览与参数；底部状态和任务进度。

## 已批准首版范围

单文件项目保存与基础恢复；TIFF/JPEG/PNG 导入；可选 2×2 降采样和可选原文件保留；多画布、总览、多选、自由摆放和作品框；分块取样与反转色；独立产物和三种展示方式；参数预设与有序步骤工作流；最多 10 张输入的批处理及进度、取消、失败反馈；JPEG/PNG/16 位 TIFF 导出。

暂缓：RAW、自动提色、局部画笔、紧密拼合、重排、复杂标签与版本关系图、节点和条件工作流、监控文件夹、专业印刷功能。

## 实现选择

- Python + PySide6：本地 Qt 桌面窗口，无服务器、无远程调用。
- NumPy + tifffile + imagecodecs：16 位 RGBA 图像处理，TIFF 无损 Deflate 压缩；Qt 图像与颜色配置支持预览和色彩转换。
- 图像像素、项目状态、工具注册表与界面分离。工具以 JSON 可保存参数和稳定标识定义。
- `.blockproj` 为 ZIP 容器，含 JSON 清单、导入源图、独立结果、预览和可选全尺寸原文件。已有结果不可被后续工具执行改写。
- 像素单位采样；间隔指保留矩形之间的空隙，周期为保留尺寸加间隔；偏移允许正负，边缘裁切。批处理对每张图片使用相同像素参数。
- 2×2 面积平均采用 alpha 加权颜色，避免透明边缘变暗；奇数尺寸保留最后一行/列并用实际样本数平均，因此宽高向上取整。不默认加锐化。
- 颜色统一在处理时转换为 sRGB，保留源文件字节；无 ICC 输入按 sRGB 解释。透明像素使用直通 alpha。
- 工作流仅手动执行；依次保存每一步产物。队列串行执行以限制内存，取消在步骤之间生效。

## 2026-09-17 · 0.2 试用反馈修订

### 问题根因

0.1 的常驻工具面板随画布选择变化。生成取样结果后，界面自动选中结果；继续调参时，执行输入变成已有透明孔洞的取样图，因此新掩膜与旧掩膜相交。64 像素周期与 80 像素周期叠加后出现截图中的残缺碎块。另一个问题是预览直接对缩略图生成网格，与完整分辨率执行的像素边界可能不一致。

### 已实现修订

- QStackedWidget 分离画布与工具二级页面。画布选择图像和工具后进入，提交新稿后返回。
