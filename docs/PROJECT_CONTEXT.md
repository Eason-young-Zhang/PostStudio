# PostStudio

一个面向艺术创作的本地图像工作台。以分块取样为首个工具，让图像中的保留、缺失、空间关系与观看者的辨认和脑补共同构成作品。

> 当前阶段：PostStudio 0.4.1 本地测试版。冷蓝主题、删除回收、精细配色布局、渐变与阴影、预设直接执行、单条节点流程、胶片资料、水印和边框均已实现。62 项自动测试通过；新版原生增强取样图像反馈 P95 约 66 ms。安装及接续记录见 [执行接续](EXECUTION_STATUS.md)，验证范围见 [0.4 验收记录](ACCEPTANCE_0_4.md)。

## 项目缘起

创作想法受到 JPEG 的 8×8 分块与 DCT 处理启发：按一定大小和间隔取样图像中的区域，将保留部分与原图并置，让信息的缺失和观看者的补全形成视觉体验。

最初形态是原位留空：保留被选中的图像块及其空间位置，其余区域透明或填充背景。空缺也可成为绘画或其他二次创作的空间。紧密拼合和重新编排是后续方向。

本项目不预设观众必须产生哪一种感受。取样大小、间隔、偏移和未来的编排规则是创作变量，由作者根据具体图像决定。首先使用风景照片实验，成品主要用于屏幕观看。

技术概念说明：可以在解码后的像素图像上实现这种分块创作，无须直接操作 JPEG 内部的 DCT 系数。是否研究实际编码域的操作尚未决定。块尺寸不限定为 8×8。“压缩展示”是创作描述，不等同于减小文件体积；信息熵与脑补目前也是创作命题，不是已定义的科学指标或产品效果承诺。

## 已确认的需求

### 运行环境与定位

- 首先仅供作者自己的 Mac 使用，本地运行。
- 素材和图像处理始终留在本机，断网可用。
- 浏览器访问作为未来开发备选；首版采用本地 Python / Qt 桌面应用。
- 界面以艺术创作体验为中心，同时提供必要的批量管理能力。
- 后续可能在 GitHub 开源或分享给朋友共同开发；尚未发布，也未选定许可证。

### 目标设备与素材规模

- 作者提供的目标设备：13 英寸 MacBook Air M5，24 GB 内存，1 TB 存储；作为开发与性能验证目标配置。
- 常用输入格式：TIFF、JPEG、PNG。
- 输入照片尺寸各异，单张总像素量在 50 MP 以下。50 MP 仅用于估算单张处理开销上限，不是默认输入尺寸、画布尺寸、作品框尺寸或统一内容规格。素材来源为胶片扫描与数字输出，各约一半，实际更常以 JPEG 输入。
- 格式偏好（经用户更正）：理想输入为 16 位/通道 sRGB TIFF，实际多数时候输入 JPEG；产物偏好以 JPEG 导出。先前“通常输出 16 位 sRGB 无压缩 TIFF”的表述为口误，不再作为输出需求。
- 不据此假定所有输入具有相同位深与色彩配置；TIFF 压缩及多页等特殊情况仍待确认。
- 外部二次创作主要使用 Photoshop 和各类绘画软件。
- 典型项目通常导入不超过 42 张原始照片，以一卷 135 摄影胶卷的工作量为参考；不是已确认的导入硬上限，处理产物数量另计。
- 一次批处理最多 10 张；这是用户操作规模，不表示必须同时处理 10 张。内部并发与队列策略待性能验证。
- 前期不处理 RAW；RAW 支持列入后续开发方向。
- 交互工程目标和实测结果见行动方案及实施记录；区分公开照片/合成素材、计算/窗口绘制，不承诺未经测试的性能。

### 项目与工作台

- 采用“项目总览＋多张自由画布＋作品框”的组织方式。
- 总览用于素材和结果的整理、筛选、多选与批量操作；自由画布用于摆放、比较、处理与构图。
- 支持导入多张图像，选择其中一部分交给某个工具处理。
- 画布与工具处于两个页面层级：在画布选择图像和工具后进入独立二级页面，生成修改稿后返回画布；返回但不生成时不新增产物。
- 工具页面固定输入，显示来源、参数和大幅预览；对同工具结果默认修改其原步骤，明确选择“追加处理”才在当前产物上继续叠加。
- 关闭工具后，处理成果保留在工作台上，可以导出或继续交给其他工具。
- 创作默认先自由摆放，再用作品框确定导出范围。
- 画布上编排好的原图与处理结果可以一起导出为作品。
- 画布页左侧切换画布列表与素材总览，顶部选择工具并进入二级页面；具体交互继续随试用反馈调整。

### 项目保存与分享

- 一个项目文件包含实际选择导入的图像、所有产物、处理参数和画布布局，复制给朋友后可以完整打开并继续创作。
- 导入降采样时，“保留全尺寸原文件”为可选项，默认关闭：关闭时项目只保存降采样后的导入图像，以其作为该分支的源图；开启时同时保存全尺寸原文件。未选择降采样时保留正常导入的原图。
- 项目完整性以本次导入选择为边界；默认降采样导入的项目不承诺恢复全尺寸。不将全尺寸原文件偷偷留在项目或作为项目依赖；此规则不删除或改写磁盘上的外部源文件。
- 项目应自包含，不依赖作者电脑上的原始素材路径或外部缓存才能恢复内容。
- 保存内容应覆盖前述输入关系、版本组织、作品框及项目内保存的预设与工作流，以保留完整创作上下文。
- `.blockproj` 采用 ZIP 容器＋JSON 清单与独立资产文件；中间 TIFF 已无损压缩，容器使用存储模式。
- 接收方需要兼容的应用版本；应用分发、未来扩展工具的兼容策略仍待讨论。
- 当前提供编辑后的本地恢复副本与手动完整项目保存；正常关闭询问保存，异常退出可恢复。完整备份管理和缓存淘汰后续完善。

### 结果与历史

- 默认保留项目中的源图，并在旁边新增处理结果；源图可以是用户选择降采样后导入的图像，全尺寸原文件是否另存遵循导入选项。
- 同时希望支持原位置显示处理结果，以及以版本集合切换和比较结果；由用户选择展示方式。
- 每个工具应记录处理参数与输入关系，支持预设、多步处理和后续追溯。
- 再次打开处理结果时，应能回头修改之前的参数。
- 各工具步骤独立执行；除非用户明确要求，不同步修改其他步骤或已有产物。
- 回头修改参数并执行后生成新的独立产物，保留原有产物。输入关系用于追溯与复用，不触发自动联动更新。
- 示例：原图经 A 取样生成 a1，a1 经 B 调色生成 b1，二者都留在工作台。回到 A 修改间隔并执行，生成 a2，a1 与 b1 保持不变；只有明确对 a2 执行 B，才生成 b2。
- 原位置显示、并排展示和版本集合仅改变展示方式，不改变上述产物保留规则。

### 首个工具：分块取样

- 优先实现原位留空，保留原有空间位置。
- 基础网格横向与纵向分别控制保留区域尺寸、间隔尺寸和起始偏移；滑块与精确数值同步，允许方向键微调。
- 支持拖动整组网格，以及单独移动某个取样窗口；单块移动改变源图上的取样位置，其他块不变，记录为可复用参数。单块不是把旧像素贴到新位置。
- 默认同工具重新编辑回到固定输入，防止无意叠加旧取样掩膜；预览按原始像素处理后再缩小，过期预览不会覆盖新参数结果。
- 块大小不固定，尺度可以调整，并提供实时预览。
- 空缺支持透明背景、自选颜色和从图像取色。
- 从整幅图提取主色或配色作为候选色，已提升为下一阶段确定需求，由独立配色提取工具提供颜色快照，现已实现。
- 支持导出带透明区域的 PNG，用于外部绘画等二次创作。
- 局部选区、画笔、强制保留区域及分区参数留待后续。
- 紧密拼合与重新编排保留为后续工具或模式。

### 工具组合与数据质量

- 工作台应可拓展，首个工具之外还能增加其他图像工具。
- 中间产物采用 16 位/通道 TIFF 作为规格上限与当前存储方向，不默认采用更高精度的持久化格式。中间 TIFF 使用 Deflate 无损压缩、直通 alpha 和 sRGB；输入有效色彩配置在处理时转换，源文件字节保留。
- 此限制针对中间产物存储；图像使用 uint16，合并与合成的中间计算使用浮点。界面使用缩略图，工具预览按需缓存一张完整输入。
- 默认不改变导入图像的像素尺寸；若用户在导入时选择降采样，后续原位取样默认保持该工作图像的像素尺寸。输出时也可选择降采样。
- 用户所称“1:4 超采样”指每个 2×2 像素区域合成为一个像素，即宽高各减半、总像素数约为四分之一。技术文档与界面应清晰标注为降采样，并显示处理前后的尺寸，避免与文件压缩混淆。
- 降采样的创作目标是在降低存储开销时尽量保留视觉锐度；不承诺无损或完全保留细节。当前采用 alpha 加权面积平均，奇数尺寸向上取整，边缘按实际样本数平均，不默认锐化。
- 导入和输出均可选择该操作；导入时“保留全尺寸原文件”默认关闭，按需开启。降采样操作默认关闭；输出选项说明会基于当前尺寸再次降采样。
- 文件无损压缩与降采样是独立选项：前者保留像素数据，后者改变像素尺寸。
- 中间产物仍采用前述 16 位 TIFF 方向；JPEG 是偏好的最终导出格式，不因此改用 JPEG 保存中间产物。透明二次创作使用 16 位 PNG；JPEG 提供质量设置，将透明区域合成所选背景后输出 8 位 sRGB。
- 支持保存单个处理方案或预设，以及多步工作流。
- 执行多步工作流应由用户明确触发；修改某一步参数不自动重跑工作流，也不改写已有产物。
- 支持对所选多张图像快速执行多步处理或批量粗处理。
- 当前 0.4 工作流支持拖入预设和排序的单条节点链，分支、合流和条件不纳入。

### 配色提取与交互性能（0.3.1）

- 用户已认可 Oklab 配色提取方案，与分块取样平行，使用独立二级页面。
- 面积主色与特色配色两种模式；默认 5 色、范围 2～12，允许锁色、图内取色与重排。
- 等宽/比例色条与色卡环，支持四侧布局或独立色卡；照片＋色卡作为可拆分组合保存并可合成导出。
- 配色与来源、参数、布局保存在项目内；重编辑产生独立版本，不自动影响其他产物。
- 先改进持续拖动、滑块、键盘调参的响应，再让新工具复用预览机制。交互快速预览、静止精细预览和正式全分辨率计算分离；坐标正确性与旧取样回归必须保留。
- 以上已在本地测试版实现；验证记录、试用边界和当时的四象限见 [0.3 已完成方案](PLAN_0_3_COMPLETED.md)。

### 0.4 已实现范围

用户已批准本轮方案。以下功能已实现，具体行为和验证边界见 [验收记录](ACCEPTANCE_0_4.md)。

- 工作台支持删除画布与项目素材；区分移出画布、回收和永久清理，保护已生成产物与重新编辑的依赖，不删除外部原文件。
- 配色布局增加精细间距、四边独立留白、色卡宽高和对齐；取色可取消并撤销；照片与色卡分别支持阴影。
- “保持当前外框比例”锁定当前外框宽高比；“外框匹配图像比例”主动切换为原照片比例。两项分别命名，均不拉伸原图。
- 取样修复色卡候选与背景按钮，增加渐变和取样块阴影；共用精细参数、颜色、撤销和取色控件。
- 预设支持直接应用到当前所选图像；工作流核心是不同图像接受相同处理，首版只做单条节点链，可排序、停用、命名与导出，无分支／合流。
- 水印为平行工具，支持多个签名、EXIF／补录字段题注与外部图片；位置、字体、颜色、透明度、混合模式可调；不做重复平铺。
- 胶片资料支持一组照片批量填写及单张覆盖，原 EXIF 与手动资料分开，不回写原文件。
- 边框为平行工具，先做外扩／内遮、纯色／渐变、多层、圆角、描边与阴影，复杂纹理与形状后续研究。
- 新工具和流程保留独立产物、离线、自包含资源及手动执行原则；缺失字体必须提示，不能保证缺字库机器精确重新排字。

## 典型使用过程

1. 创建或打开项目，导入一些图像。
2. 在总览整理素材，将需要创作的图像放入自由画布。
3. 选择一张或多张图像，点击画布右侧独立工具栏的按钮进入二级页面，用滑块、精确输入或拖动取样窗口调整效果。
4. 应用处理，默认在原图旁保留新结果；关闭工具后继续在画布工作。
5. 将部分结果交给其他工具处理，或回头调整已有步骤的参数并生成新产物；原有产物保留，其他步骤不自动执行。
6. 自由摆放与比较图像，最后用作品框划定构图并导出；也可单独导出图像。
7. 将可复用的处理参数或步骤保存为预设或工作流，用于其他图像。

以上流程已有实现；自动化验证与尚待真实素材验收的范围见实施记录。
