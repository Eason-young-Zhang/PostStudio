## 1. 本轮结果与既有约定

完成后，用户可以整理和删除画布／项目素材，精细排版色卡与留白，为取样添加渐变和阴影，制作边框和多个水印，并将预设组装成单条流程，对选中的一组图片一键顺序处理、命名和导出。

必须保留：

- 本地离线处理，不上传素材；项目自包含，可复制给兼容应用打开。
- 画布与工具分层；所有图像处理工具使用独立二级页面。
- 输入和已有产物不被改写；处理生成新版本，后续步骤不自动联动。
- 中间存储维持 16 位 RGBA sRGB TIFF 无损压缩；8 位原图不因此获得额外细节。
- 导入与导出降采样规则、全尺寸原文件保留选项保持既定行为。
- 单批工具／工作流最多 10 张，逐张逐步处理；典型项目 42 张，50 MP 为单张资源规划参考，不是画布规格。
- 不把已有 32 项测试与旧性能数字当作本轮通过证明。

### 共识与本方案默认值

用户明确确认：单条批量流程优先；签名与拍摄题注优先、不做重复水印；允许批量补录胶片资料；先做简单边框；“保持当前外框比例”和“外框匹配图像比例”语义分开。

本文件为减少执行歧义提出具体默认值：回收站与依赖保护、1 px／0.1% 精度、初始渐变类型、阴影裁切、缺失字段策略、工作流失败与导出行为等。它们是**待本方案一并审阅的设计选择**，不冒充用户逐项指定的要求。批准方案后，常规实现细节按这些默认值推进，不重复要求确认。

## 2. 工作台：删除与恢复

### 2.1 删除画布

画布列表增加“删除画布”和右键入口，提示画布名称及摆放数量。删除的是该画布、布局和作品框，素材仍在总览中。支持撤销／恢复布局；最后一张画布删除后自动创建空白画布，保证工作台可操作。

### 2.2 删除项目图像

明确区分三个动作：

| 动作 | 结果 |
| --- | --- |
| 移出画布 | 只移除当前摆放，其他画布和总览保留 |
| 移入项目回收站 | 从总览、版本候选及各画布正常显示中移除；记录原摆放供恢复 |
| 清理回收站 | 仅永久清理不再被任何存活资产、组合、历史步骤或资源引用的内容 |

删除前显示影响范围，不自动连带删除后续产物。被结果重新编辑所需的原图、被组合引用的组件即使已移入回收站，也保留必要数据。清理时明确列出“可释放”和“仍被引用”项目，不造成悬空引用。

回收站随项目保存，重开后仍可恢复。删除画布也应保留可恢复的布局记录。清理回收站是显式不可撤销动作，应用内需单独确认，显示预计可释放空间；恢复记录所需资源也计入引用。任何动作都不删除外部磁盘原文件。

## 3. 共用交互：撤销、取色、参数与颜色

### 3.1 撤销与取色

- 工具页面支持 ⌘Z／⌘⇧Z：参数、取色、排序、图层增删、拖动和尺寸变化。
- 一次按下至松开的滑块／拖动作为一次撤销；数值输入确认作为一次撤销，不把每个预览帧入栈。
- 取色进入明确临时模式，显示“点击取色／Esc 取消”和取消按钮。取消不改参数；完成后自动退出；已完成的取色可撤销。
- 切换工具、输入或返回画布时结束取色。焦点在文本输入框时，快捷键先作用于文本编辑。
- 工作台撤销覆盖布局、删除和资料编辑等可逆操作；不跨页撤销已经生成的图像，也不撤回磁盘导出文件。工具编辑历史为会话内历史，项目保存最终状态和回收站，不承诺持久化完整撤销栈。

### 3.2 数值与颜色控件

像素尺寸最小步长 1 px，百分比最小步长 0.1%；支持滑块、直接输入与方向键。连续拖动快速预览，停手精细预览，正式生成取最新参数快照。百分比转像素时统一取整，界面显示最终像素值。

项目色卡选择改为**可见色块＋来源色卡名称＋色值**，可显示占比；不能仅显示 RGB 文本。颜色按钮色块绘制限制在按钮内容区，适配 Retina、窄面板和缩放。

共用背景编辑器支持透明、纯色、线性渐变和径向渐变。渐变至少两个色标，支持增删、位置、颜色和透明度；线性可调方向，径向可调中心与范围。插值统一采用 Oklab，超出 sRGB 范围时按一致规则映射；透明插值避免黑边。渐变覆盖整个作品／取样背景，不按单块重复。

### 3.3 共用阴影

默认关闭。参数为颜色、透明度、模糊、水平／垂直偏移，支持像素或相对短边单位。基于对象透明轮廓投影，不对透明矩形空白投影，不改变源图。

照片、色卡、边框、水印与取样复用参数和渲染规则，按对象保存开关。默认在当前输出范围内裁切，预览显示裁切影响；不因加阴影偷偷扩大输出。外扩留白后可容纳完整阴影。正式处理采用有界缓存／分带等方式控制大图内存。

## 4. 配色工具：精细布局与比例语义

### 4.1 尺寸、位置与四边留白

保留 Oklab 提色与锁色行为，布局调整不重新提色。

- 间距、留边增加精细数值；上右下左分别设置，可同值联动或独立。
- 色卡宽、高独立设置，支持比例单位；保留“填满可用长度”快捷选项，但不再强制占满照片宽／高。
- 位于上下侧时可左／中／右对齐，位于左右侧时可上／中／下对齐；另可精确偏移。
- 色条宽高独立；色卡环默认锁定 1:1，可显式解除以形成椭圆，不能无提示拉伸。
- 照片与色卡分别控制阴影；色卡文字随空间约束排版，无法容纳时明确提示。

### 4.2 两项比例功能必须区分

| 界面语义 | 行为 |
| --- | --- |
| 保持当前外框比例 | 锁住启用时外框的宽高比；修改宽或高时联动另一边，不要求与照片同形 |
| 外框匹配图像比例 | 主动将外框设为输入照片宽高比，再保持该比例缩放 |

例：照片 3:2，当前外框 4:3。“保持当前外框比例”继续保持 4:3；“外框匹配图像比例”将其改为 3:2。比例功能改变外围画布，不拉伸照片或色卡。

外框与内部内容分开控制：支持定位照片／色卡内容组，分配剩余留白，产生不对称边距。锁定比例时修改一边留白，自动调整外围尺寸及对侧／另一轴留白，并在界面显示被联动值；选择完全独立的四边编辑时，明确关闭比例锁，不静默保持一半约束。

配色布局的最小外框必须容纳照片、色卡及间距。匹配比例时取能容纳内容的最小同比例外框；手动缩到更小时提示并限制，不压缩照片或裁掉色卡。照片 3:2 不意味着增加色卡后的紧凑内容组也是 3:2。

外扩边框工具共用这些比例语义；内遮模式的外部输出尺寸固定，因此外框缩放控件禁用并说明原因。最终像素取整允许不超过 1 px 的比例误差。

## 5. 分块取样：背景与块阴影

- 修复项目色卡候选缺少可视色块和背景按钮色块溢出。
- 背景支持透明、纯色、线性／径向渐变；保存完整渐变参数，选择项目色卡颜色保存独立快照。
- 增加“取样块阴影”，置于背景之上、保留图像之下。使用最终取样窗口覆盖区与源 alpha 的合成轮廓投影；窗口重叠先取并集，不重复加深重叠阴影或制造内部接缝。
- 维持完整工作尺寸，边缘阴影按输出边界裁切。取样背景透明时允许仅保留图像与半透明阴影，便于绘画。
- 保留网格偏移、单块移动、重编辑固定输入和旧结果不变的语义。

## 6. 预设与单条节点工作流

### 6.1 预设直接执行

工作台预设区增加“应用到所选”，保留“打开调整”，支持重命名、复制、删除及摘要。直接应用将预设追加到当前选中的素材，不自动回到其父输入；修改原步骤仍从“重新编辑”进入。显示选择数量和放置方式；批量预览按需选看，不能将第一张预览误标为全部结果。

### 6.2 编辑流程

独立流程页面：左侧预设／动作库，中间一条节点链，右侧节点设置。拖入预设、拖动排序、停用、复制、删除节点；连接只能形成单条链，阻止分支、环路和合流。

预设拖入时复制参数和所需资源引用。之后修改或删除预设，不影响已有流程；“从预设更新”是明确动作，不自动执行。工作流可命名、复制和删除。

节点分三类：

| 类型 | 行为 |
| --- | --- |
| 图像处理 | 取样、反转色、配色、边框、水印；每步生成独立产物 |
| 命名 | 修改本次运行的结果名称／后续导出名，不回写外部原文件、不改历史图像 |
| 导出 | 写出当前步骤结果，保留工作分辨率供后续节点处理；不额外创建像素产物 |

命名模板支持原文件名、自定义文字、序号、拍摄日期及可用资料字段。序号按本次输入队列固定顺序计算，显示示例与缺失字段提示，清理非法文件名字符。纯命名流程使用独立命名记录／引用，不篡改源资产身份。

导出保存格式、质量、降采样、透明底合成、文件名模板与目录。可在链中安排多个导出节点；导出降采样不改变后续步骤输入。移植项目到另一台机器，目标目录需重新选择时只在运行前集中提示。同名文件默认追加编号。

### 6.3 运行规则

1. 选择最多 10 张输入，选择流程。
2. 运行前一次检查模板、资源、缺失字体、输出目录和有效步骤，显示数量与预计动作。
3. 冻结输入 ID、预设参数、字段资料及本次放置方式；逐张执行完整单条流程。
4. 可查看逐张／逐步进度并请求取消；当前不可中断步骤完成后停止，已完成产物和导出文件保留。
5. 某张图像任一步失败，默认停止该图的余下步骤并继续下一张；导出失败也计入，报告已有成功文件，不声称全成功。
6. 完成报告列出输入、产物、导出路径、跳过／失败原因；重新运行生成新结果，不覆盖旧版本。

参数语义为“相同规则，各自内容”：固定像素参数数值相同；百分比随每张图尺寸计算；自动提色按每张图提取；手动锁定配色复用；水印字段按每张图替换。流程不加入上一张图的取色坐标或 EXIF 文本快照。

默认在旁新增最终结果以控制画布拥挤；可选展示所有中间产物、原位置显示或版本集合。所有图像处理节点的中间产物仍存于总览。旧流程转换时保留步骤顺序、参数和原放置语义，不强行采用新默认。

## 7. 胶片资料与水印工具

### 7.1 元数据和手动补录

导入时保存可读取的 EXIF 原始字段及用于显示的规范化值；区分拍摄日期和文件时间、拍摄相机和扫描设备，缺失不猜测。用户补录为单独项目资料层，支持相机、镜头、胶卷型号、感光度、拍摄日期／地点、冲洗、扫描与备注。总览多选后可批量填写，显示“混合值”，只改明确编辑的字段；单张可覆盖，清除覆盖后回到批量值／原字段。

字段沿产物来源保留。流程执行冻结此次解析值和来源，既有水印不因后续补录变化而重绘；重新执行可使用当前资料，界面明确说明。旧项目优先从保留的原文件补读；无法读取时显示缺失，允许手动填写。工作图像尺寸与原始拍摄字段分开。

### 7.2 多水印层

新建与其他工具平行的“水印”二级页面。可添加文字／字段模板层和图片层，独立选择、命名、复制、删除、排序与隐藏。主要场景为角落签名和拍摄参数题注，不做重复平铺。

文字可混用自由文本和点击插入的字段，例如“{相机型号} · {焦距}”。显示每张输入的解析预览；缺失字段默认隐藏片段并整理关联分隔符，允许占位文字或将该张视为失败。自由文本不被误删。

每层支持九宫格定位、拖动、精确偏移、旋转、大小、颜色、透明度；文字支持字体、字重、行距、字距和对齐，图片默认锁定长宽比。像素与百分比单位明确参考区域。首批混合模式为正常、正片叠底、滤色、叠加、柔光、差值，并可设置描边／阴影。

定位参考可选整张输出、可用的原照片区域、边框区域。边框题注可在下边框居中；若上游工具使区域失效，明确提示并让用户选择整图参考，不能偷偷放错位置。超长文字支持在给定宽度内换行或自动缩小，显示溢出提示，默认不无提示裁字。

图片水印嵌入项目并随预设／流程保留引用。字体首版使用本机可用字体；缺失时显式选择替代。项目仍能显示已生成水印产物，但精确重编辑需要原字体。自动携带字体不纳入本轮，不宣称复制项目即可在缺字库的机器上完全一致地重新排字。

## 8. 快速边框工具

- 新建独立“边框”二级页面，支持多层及拖动排序，每层可外扩或内遮，显示操作顺序。
- 外扩增加画布，不重采样源图；内遮保持输出尺寸，覆盖边缘，不改源文件。每层作用于前一层结果。
- 四边宽度支持同值、成对、独立与比例尺寸；外框比例遵循第 4 节的两个明确选项。
- 首版支持纯色、线性／径向渐变、透明度、填充或描边、圆角、阴影；圆角作用于该层外轮廓／内开口，显示透明角落，不偷偷裁切原图。
- 内遮宽度必须保留有效开口；非法几何提前提示，禁止负尺寸或空洞反转。
- 提供简洁起点：细线框、四周留白、下方加宽题注框、双层边框。模板均可修改，不是固定成品。
- 保存原照片区域、各边框区域与相对位置，以供下游水印定位；无法可靠保留的区域要标记失效。
- 不做纸张纹理、撕边、齿孔或写实材质。这些后续可研究开源实现，先检查许可证与离线适配，不预设必须新增依赖。

## 9. 数据、兼容与执行结构

扩展项目清单，版本号按实际字段变更确定；不得将新格式冒充 v2。新增回收站、资料、资源、布局区域、背景／阴影及有类型的流程节点；工具各自升级参数版本，旧参数补默认值后保持旧视觉结果。

旧 v1/v2 项目只读加载后在内存迁移，首次保存新能力建议另存新文件。未知工具、未来版本、失效资源及循环引用明确报错，不静默跳过。新功能不保证旧应用可打开新项目。

删除使用统一引用检查，覆盖 parent/root、组合、资源、预设、流程、回收站和恢复记录。暂时合成缓存不进入项目包，资源路径仍限制在受管理范围。项目不携带可执行代码，元数据、文件名模板只当数据解析。

图像工具通过版本化参数处理不可变输入；命名／导出作为独立动作节点，不伪装成图像滤镜。预览与正式处理共享几何、色彩和合成规则，精度／尺寸可以分级；尺寸约束与 100 MP 合成保护在分配大数组之前检查，并计入阴影中间开销。

## 11. 验收标准

| 编号 | 必须验证的场景 |
| --- | --- |
| A01 删除 | 多画布引用同素材；删除最后画布；素材被组合和后续步骤引用；保存重开后恢复；清理只释放无引用资源；外部原文件未动 |
| A02 撤销取色 | Esc／按钮取消无变化；取色完成可撤销重做；一次拖动一次撤销；文本焦点正确；退出页面无悬挂取色 |
| A03 布局 | 间距 0.1%／1 px；四边不对称；色卡自定宽高及六种方向对齐；4:3 外框锁定与匹配 3:2 图像行为不同；不拉伸图像 |
| A04 颜色与阴影 | 候选色可看可选；按钮无溢出；渐变透明边缘无黑边；窗口重叠无重复加深；照片与色卡阴影独立；边界裁切可预见 |
| A05 预设 | 工作台多选直接执行；输入确为所选；旧产物不变；修改／删除库预设不影响已有流程；依赖水印资源仍存在 |
| A06 字段 | 不同 EXIF、无 EXIF、扫描设备信息；批量补录和单张覆盖；旧项目缺失提示；每张使用自己的字段；已生成文字不联动 |
| A07 水印 | 多层文字／图片、中文字体、缺失字体提示、长题注、透明图标、混合模式、照片／边框定位、取消与撤销 |
| A08 边框 | 外扩原像素不变；内遮输出尺寸不变；多层混合顺序；圆角透明；非法开口拦截；下游题注定位正确 |
| A09 流程 | 10 张不同内容／方向／尺寸图像；停用和排序；中途导出后继续；命名和重名；失效目录；单图失败继续；取消后报告已完成文件 |
| A10 项目 | v1/v2 迁移、参数兼容、复制到新位置、删除缓存后离线重开；水印图与预设资源完整；未知版本不覆盖 |
| A11 性能 | 小图、约 24 MP、近 50 MP，42 张素材、10 张批处理；记录峰值内存和交互延迟；新增效果不得令连续拖动持续停更 |
| A12 交付 | JPEG、透明 PNG、16 位 TIFF 对照；实际安装包操作、项目重开；手册只写已实现行为，未测第三方往返如实标注 |

像素与引用逻辑使用有价值的自动验证；操作手感、控件溢出、取色退出、拖动节点和字体呈现必须实际 GUI 验证。保留先前取样不错误叠加、快速／精细预览无倒退、独立版本和降采样回归。性能目标沿用事件到几何 P95 ≤ 50 ms、缓存就绪的交互图像 P95 ≤ 100 ms 作为测量目标，首次解码和复杂效果单独报告，不保证所有新效果都达到同一帧率。

## 13. 四象限与剩余未知

| 象限 | 当前内容 | 处理方法 |
| --- | --- | --- |
