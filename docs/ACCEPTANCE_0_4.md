## 本轮性能

公开摄影素材 Fronalpstock（Hannes Röst，CC BY-SA 3.0），10109×4542，约45.9MP。原生 Cocoa 10秒输入416次、绘制392次，几何反馈 P95 20.16ms，图像反馈 P95 65.68ms，启用渐变与阴影。范围是 Qt 事件调度到绘制结束，不包含显示器物理呈现。报告：`artifacts/v04/release-validation.json`。

42 张输入场景重复同一公开照片，共44资产、43摆放，刷新0.258秒，峰值RSS2640.5MiB。不能视作42张不同照片的普遍保证。

CPU 合成 RGBA16 测试 `artifacts/effects-v04.json`：0.96/24/48MP 交互中位16.94/16.64/13.72ms；完整渲染0.125/3.150/6.216秒；48MP进程峰值2351.5MiB。交互使用560px效果缓存并复用背景，静止与正式渲染保留完整工作分辨率。新请求可取消精细增强取样，减少排队。

## 已知边界

- 本地测试包，未 Apple Developer 公证，未发布 GitHub；许可证与第三方分发声明仍需正式发布前整理。
- 字体不随项目嵌入；缺字库机器可显示既有像素结果，重排需选字体。
- 没有私人胶片扫描、特殊 ICC 与 Photoshop／绘画软件往返验证。
- 外框留白使用最小留白＋实际像素反馈，比例锁与独立四边可共同存在；不会拉伸内部照片。与最初草案“独立编辑关闭比例锁”的设想有所调整，已在界面与手册说明。
